# Kino
Kino is a rust programm, wich:
- Hosts all movies from a given folder on a Website
- fetches info about movies from http://omdbapi.com/
- display movies in a "nice" website
# How to run
- check in constant file if all paths are correct
- parse your omdbapi Key as env! argument 
- cargo run --release
- Website will be hosted on port 3000
